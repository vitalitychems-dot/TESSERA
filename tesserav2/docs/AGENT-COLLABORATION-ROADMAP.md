## Current boundary

- Gitbook contains the shared world-model snapshot, provenance-memory contract, execution board, and the three attributable audit reports produced so far.
- TESSERA code changes require a claimed task, exact scope, acceptance tests, independent verification, and the normal Gitbook Moderator/Build/human approval gates.
- AGI-03 task-planner implementation is **not** claimed or merged: its analysis requires a database migration decision, an assigned owner, isolated PostgreSQL tests, and review.
- No repository content here proves true AGI, consciousness, autonomy, or biological equivalence. Those remain open research goals.

## Development rule

Do not implement a TESSERA change from a Gitbook proposal alone. Link the TESSERA commit back to its Gitbook task, evidence, tests, limitations, and approval digest.
