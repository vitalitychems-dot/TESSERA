# data/facets (SAMPLE DATA)

Default folder the HUD (`hud/`) watches. Every file here is one tile in the 3D terrain.
The `SAMPLE-*.tsv` files are made-up sample data in the crystal.tsv row shape from
`vitalitychems-dot/memory` `crystal/` (`date<TAB>lane<TAB>kind<TAB>name<TAB>path`).
They are not real facets. Point the HUD at a real folder with `HUD_FACETS_DIR=/path`.
