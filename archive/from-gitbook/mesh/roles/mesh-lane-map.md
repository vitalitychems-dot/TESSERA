## Delivery sync ≠ Father push

~30–45 min mesh bulk sync (when all agents finish the last synced task) is **auto-yes for agent sync**. Path: Moderator → TESSERA gate → Security → CI/Build → one Tessera bulk update (Command Center feeds it). Auto-yes for agent sync never authorizes a push or merge; only Father’s final yes does. That sync is **not** Father’s GitHub push.

**Current** — cadence (Father, 2026-10-06 6:32 PM CT): an item that passes both the TESSERA gate and Gitbook Moderator review is auto-yessed and pushed after the Security scrub (no PII, personal addresses, phones, emails, tokens, or chat-log dumps with personal data; no secrets) by **Ready** (the Ready agent); changes to code, validators or scripts also need CI/Build first (docs-only skip Build). Father gets one clean combined numbered list every 45 minutes, with a real health check. He can undo any item by its GB number; an undo is a revert commit, never a force-push. There are no other drips to Father. TESSERA merges and Origin main merges still need Father's word `merge`. The paragraph above records the earlier rule.
