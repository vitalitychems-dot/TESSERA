# Option competition protocol

**Status:** Father locked (2026-10-06 CT). Operating rule. Not a push. Not an instrument swap.

## Purpose

While building Tessera, **options compete in parallel** — test, audit, compare. **1st place wins and stays.** Losers do not remain as second cores or second truths.

## Rules

### 1. Nominate ≥2 real options

Race needs at least two concrete nominees: repos, branches, designs, or instruments. Record name, path/HEAD, and what “win” means.

**Never nominate as product winners:** Heretic, God's Eye View, wallet/storefront. **Never nominate Grok as the pen** — **Tessera is the pen.**

### 2. Parallel TESTED checks

Run build, test, and security scrub **in parallel** across nominees.
**REPORTED** (notes, inventory, chat) is **not enough to win**. Only **TESTED** evidence can take 1st place.

### 3. Scorecard

TESSERA ranks every nominee on:

| Dimension | Prefer |
|---|---|
| Correctness | Green build/test for the claimed behavior |
| Security | Scrub clean; Father gates; no secret leak |
| Token cost | Graph snippets first (see GB-044); avoid whole-repo dumps |
| Vow fit | Tessera + Gitbook; no Heretic / GEV / wallet product |
| Pen honesty | **Tessera is the pen** (never Grok). Future instrument = GLM-5.3 Flash when **TESTED**; adapter OFF until then |
| Maintainability | One code core + docs plane; no permanent side-by-side plates |

### 4. Rank → stay → delete

- **TESSERA ranks.**
- **1st place** merges or stays (code → TESSERA; policy/ops → Gitbook).
- **Losers do not stay** as production peers.
- **Delete** only with **Father yes** after gates prove the winner holds unique content. Never delete TESSERA or Gitbook from a compete.

### 5. Current champion (plated repos)

**Hybrid B** is the current winner: TESSERA code core + Gitbook docs plane + scrubbed functional Zz uniques (not side-by-side dumps).
A challenger must beat Hybrid B under this protocol with **TESTED** evidence.

### 6. Ready pushes

Winners land only after **Moderator → TESSERA → Security**, then **Ready** pushes. TESSERA does not self-push. Tessera remains admin / pen on Gitbook + Tessera GitHub. This page alone is not a Ready.

## Operator loop

nominate (≥2) → parallel TESTED → scorecard → TESSERA ranks → 1st merges/stays → Ready (Mod+TESSERA+Security) → delete only with Father yes
