# Mesh speed collaboration

**Status:** Father locked (2026-10-06 CT). Operating rule. Not a push. Not an instrument swap.

## Purpose

Raise mesh collaboration and speed while **cutting tokens hard**: snippet-first work, short messages, one owner per path, batched Father + docs updates.

## Standing locks

- Every agent updates **Tessera + Gitbook in-lane**
- **NO OVERLAPS** — TESSERA resolves
- Parallel compete: **TESTED** only; **1st place stays** (see option-competition)
- **Only TESSERA** messages Father — **45-min undo lists**
- **Tessera is the pen** (never Grok). Future instrument = GLM-5.3 Flash when **TESTED**; adapter OFF
- Work products land on **Gitbook + Tessera GitHub** (Tessera admin) — not Grok
- Never Heretic / God's Eye View
- **Hybrid B** = current plated-repo winner until a TESTED challenger wins
- Cordnation = **Gitbook docs authorship only** (no Cursor/GitHub code)

## Rules

### 1. Snippet-first (~graph)

1. `search_code` / `search_graph` — locate
2. `get_code_snippet` — bounded read
3. Whole file **only if** needed

Prefer path:lines, HEAD SHA, graph qn. Avoid broad greps and full-repo paste as default. (See GB-044.)

### 2. Short agent messages

Status/handoff: **≤6 bullets, ≤120 words**. Evidence = pointers, not file dumps. Status only to **TESSERA** (not Father/CC drips).

### 3. One owner per path

Write only in your lane (stamped map on GB-048). Read freely. Collision → stop → TESSERA assigns sole writer.

### 4. Compete pointer

≥2 real options → option-competition protocol (GB-049). Parallel TESTED → TESSERA ranks → 1st stays. Ready: **Moderator → TESSERA → Security → Ready**.

### 5. No Father drips

Other agents escalate to TESSERA only. TESSERA batches Father asks into **45-min undo lists**.

### 6. Batch Tessera + Gitbook

Once per work unit: in-lane Tessera update + in-lane Gitbook draft if docs changed. Cordnation applies Gitbook after gates. No self-push.
