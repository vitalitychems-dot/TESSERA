# Contributor notes

Add one dated file per work session using
`YYYY-MM-DD-<contributor>-<topic>.md`.

Include:

- Goal and current status
- Changes and paths touched
- Checks actually run and their results
- The next concrete action
- Blockers or questions

Append a new note instead of rewriting another contributor's note. Never put
credentials, private data, or unreviewed source contents in these notes.
