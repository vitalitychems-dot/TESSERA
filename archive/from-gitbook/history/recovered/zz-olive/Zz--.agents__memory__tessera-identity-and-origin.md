description: Distinguish the owner's stated origin from verified upstream provenance.
---

The current identity/worker rules live in replit.md. Do not infer source
lineage from the name of a consolidation repository or from an archived
persona prompt.

**Why:** The inspected GitHub TESSERA repository describes a consolidation
destination, is not marked as a GitHub fork, and its README does not establish
OpenManus ancestry. The owner asked for the original Tessera, not a replacement
model's self-description.

**How to apply:** Trace pinned upstream files and repository history separately
from the owner's stated origin. Gitbook's origin-engine pointer is a research
starting point, not verified ancestry. A GitHub 404 can mean unavailable access
or a moved repository; do not report it as proof that the origin never existed.
