This folder carries the reviewed documentation from the small handoff/index
repository `vitalitychems-dot/z`. Its original `README.md`, `CATALOG.md`, and
`WALK.md`, plus its new shared `TESSERA_AGENT_HANDOFF.md`, are copied here. Its
referenced source repositories were not copied as part of this documentation

linked repository or file. The current boundaries in the root `AGENTS.md` take
precedence. In particular, the protected `1T` repository, `data/ingest`, and
external `collink1007/z` remain out of scope unless the user separately
authorizes a specific review. The original Drive file links were omitted from
the copied catalog pending review.
